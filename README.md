# 🎵 Tyller Six 8 - Distribuição & Divulgação Musical

O **Tyller Six 8** é uma plataforma web moderna desenvolvida para centralizar a divulgação de lançamentos musicais, EPs e projetos culturais. O site funciona como um blog dinâmico que conecta artistas independentes ao público e a redes de parcerias.

---

## 🚀 Funcionalidades Principais

* **Vitrine de Projetos:** Carrossel horizontal para destacar álbuns e EPs.
* **Feed de Lançamentos:** Postagens com players de áudio integrados e capas em alta definição.
* **Sistema de Download:** Botão direto para baixar faixas em MP3.
* **Solicitação de Divulgação:** Formulário integrado para artistas externos enviarem seus projetos.
* **Interface Responsiva:** Otimizado para visualização em computadores e dispositivos móveis.
* **Parcerias:** Área dedicada para curadores, playlists de Spotify e canais de YouTube.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web puras para garantir máxima velocidade e compatibilidade:

* **HTML5:** Estrutura e marcação.
* **CSS3:** Design moderno com variáveis e layout em Grid/Flexbox.
* **JavaScript (Vanilla):** Lógica de renderização dinâmica e manipulação de áudio.
* **Formspree:** Integração de formulário para recebimento de e-mails.
